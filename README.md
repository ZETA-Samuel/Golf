Golf 

A simple 2D golf game built with Python and Pygame, playable in your browser using Pygbag.

--How to Play--

Click and drag the golf ball to aim.

Pull back to set your power.

Release to shoot the ball toward the hole.

Complete each level in as few strokes as possible.

Press Enter to continue after completing a level.

-- Built With --

Python

Pygame

Pygbag
